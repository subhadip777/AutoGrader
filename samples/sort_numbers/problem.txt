Problem: Sort the Numbers

Read an integer n, then n integers. Print the n integers in non-decreasing order on one line,
separated by single spaces, followed by a newline.

Input format
Line 1: n (1 <= n <= 200000)
Line 2: n integers v1 ... vn (-1000000000 <= vi <= 1000000000)

Output format
The sorted values on one line, separated by single spaces.

Your solution must run in O(n log n) time.

Example
Input:
5
3 -1 2 3 0
Output:
-1 0 2 3 3
